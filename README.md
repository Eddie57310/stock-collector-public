## 第一次使用

### 1. 安装依赖

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. 全量采集（首次运行，采集所有数据）

```bash
./venv/bin/python main.py
```

首次运行会下载 2022 年至今的全部公告 PDF、财务数据、新闻和投资者关系活动 PDF，耗时较长（视网络情况约 10–30 分钟）。

## 后续定期更新

不同数据建议按不同频率更新：

### 每周更新新闻

```bash
./venv/bin/python main.py -m news
```

每次自动覆盖最新资讯，无需手动删除旧文件。

### 每月更新财务数据（含最新股价）

```bash
./venv/bin/python main.py -m fin
```

自动追加新月份股价，行情快照（最新价/市值/PE/PB）每次强制刷新。

### 每季度更新（财报发布后）

季报窗口通常为：**1月底、4月底、8月底、10月底**

```bash
# 下载新增公告PDF（年报/半年报/季报 + 重要临时公告）
./venv/bin/python main.py -m ann

# 更新财务数据（追加新报告期数据）
./venv/bin/python main.py -m fin

# 下载新增投资者关系活动PDF
./venv/bin/python main.py -m ir
```

或者一次性全部更新：

```bash
./venv/bin/python main.py
```

> 公告 PDF 和投资者关系 PDF 已有文件自动跳过，只下载新增内容，重复运行安全。

## 采集内容

### 模块1：公告PDF（`output/pdfs/`）

每支股票独立文件夹，分两类：

**定期报告**（`定期报告/`）
- 年度报告（全文 + 摘要）、半年度报告、一季度/三季度报告
- 时间范围：2022年至今
- 来源：巨潮资讯

**重要临时公告**（`重要临时公告/`）
- 按关键词过滤：重大合同、收购并购、定增募资、业绩预告/快报、股权激励、回购分红、关联交易、诉讼处罚等

### 模块2：财务数据（`output/financials/`）

每支股票一个 Markdown 文件，包含：

| 数据项 | 内容 |
|--------|------|
| 当前行情快照 | 最新价、总市值、PE-TTM、PB |
| 利润表 | 营收、净利润、归母净利润、研发费用、同比增速（历史全量） |
| 盈利质量 | 毛利率、净利率、ROE、ROA |
| 环比增速 | 营收/归母净利润/研发费用的季度环比 |
| 资产负债表 | 总资产、总负债、货币资金、应收账款、存货、借款 |
| 现金流量表 | 经营/投资/筹资净现金流、自由现金流 |
| 月度股价走势 | 2022年至今月度OHLCV（前复权） |
| 分红历史 | 近10次分红记录 |

### 模块3：新闻资讯（`output/news/`）

- 每支股票近期资讯（约10条/股，来源：东方财富）
- `_行业快讯.md`：财联社电报中含"半导体/光模块/PCB/AI芯片"关键词的条目

### 模块4：投资者关系活动（`output/pdfs/{代码_名称}/投资者关系活动/`）

从巨潮资讯下载每支股票的**投资者关系活动记录表 PDF**，保存至各股票的 pdfs 子目录下：

- 涵盖实地调研、电话会议、视频交流、业绩说明会、路演等各类活动
- 时间范围：2022年至今
- 已有PDF自动跳过，只下载新增
- 来源：巨潮资讯（官方法定披露平台）

## 喂给 NotebookLM 的建议顺序

1. **年报PDF**（最权威，含管理层讨论、风险因素、业务拆分）
2. **财务摘要.md**（结构化数字，可做跨股比较分析）
3. **重要临时公告PDF**（重大合同、定增、处罚等关键事件）
4. **资讯.md**（近期市场动态和舆论）
